# Age-Adaptive Pedagogy Standard

Этот стандарт дополняет `PEDAGOGY_V2.md` и отвечает на вопрос: **как преподавать один и тот же математический навык ученикам разного уровня подготовки?**

---

# 1. Два режима курса

## FOUNDATION

Для ученика, который ещё строит школьную базу.

Порядок подачи:

```text
CONCRETE
реальная ситуация / предметы / деньги / расстояние
    ↓
VISUAL
bar model / таблица / весы / number line / diagram
    ↓
VERBAL
объяснение простыми словами
    ↓
SYMBOLIC
x, y, formula
    ↓
ENGLISH SAT TERM
короткая английская формулировка
```

Главная цель:

> Понять идею и научиться объяснять её своими словами.

## SAT BRIDGE

Для ученика, уже владеющего базовой школьной математикой.

Порядок:

```text
PREREQUISITE CHECK
    ↓
PATTERN
    ↓
METHOD CHOICE
    ↓
WORKED EXAMPLE
    ↓
VARIATION
    ↓
SAT WORDING
    ↓
TRANSFER
    ↓
TIMED PRACTICE
```

Главная цель:

> Быстро узнавать паттерн и выбирать надёжный способ решения.

---

# 2. Обязательный Prerequisite Gate

Перед сложной темой урок должен отвечать:

### Before you start — я готов, если умею

- [ ] prerequisite 1;
- [ ] prerequisite 2;
- [ ] prerequisite 3.

Если два пункта из трёх не выполняются уверенно, ученик сначала проходит bridge-module.

Это особенно важно для:

- linear functions;
- systems;
- inequalities;
- quadratics;
- polynomials;
- rational/radical equations;
- trigonometry;
- circles with radians/unit circle;
- statistical inference.

---

# 3. Стандарт объяснения нового правила

Нельзя начинать с формулы, если правило можно вывести из смысла.

## Плохо

> Percent increase: `new=old(1+r)`.

## Лучше

> Было 100%. Добавили 15%. Стало 115% исходного.
>
> `115% = 1.15`, поэтому новое значение — `old × 1.15`.

Формула появляется **после объяснения**, а не вместо него.

# 4. Worked Example Ladder

Для центрального паттерна нужны минимум три прохода.

## Level 1 — Think Aloud

Преподаватель показывает ход мысли:

```text
Что известно?
Что спрашивают?
Какой паттерн?
Почему выбираю этот метод?
Что делаю первым?
Как проверяю?
```

## Level 2 — Same Pattern, Different Clothes

Меняются числа, порядок данных или контекст. Подсказок меньше.

## Level 3 — Faded Example

Ученик заполняет пропуски:

```text
Pattern: ______
First step: ______
Why: ______
Check: ______
```

Только после этого идёт самостоятельная SAT-style задача.

---

# 5. Vocabulary Staging

Новый термин вводится в три слоя.

### 1. По-простому

> число перед `x`

### 2. Математический термин

> coefficient

### 3. Экзаменационная фраза

> the coefficient of `x`

Для Foundation нельзя нагружать предложение несколькими новыми английскими терминами одновременно.

---

# 6. Правило одного нового барьера

В обучающем примере желательно менять **одну сложность за раз**.

Например для percentages:

1. простые числа + русский текст;
2. другие числа;
3. decimal;
4. English SAT wording;
5. reverse percent;
6. multi-step context.

Не следует одновременно давать:

- новый математический паттерн;
- сложные дроби;
- новый английский термин;
- непривычный контекст.

Иначе непонятно, что именно вызвало ошибку.

# 7. Concrete → Visual → Symbolic examples

## Equation

```text
CONCRETE
В коробке неизвестное число карандашей.
Добавили 7. Стало 12.

VISUAL
[ ? ] + [7] = [12]

SYMBOLIC
x + 7 = 12
```

## Percentage

```text
CONCRETE
100 тенге = 100%

VISUAL
██████████ 100%
███        30%

SYMBOLIC
0.30 × 100 = 30
```

## Ratio

```text
2 red for every 3 blue

R R | B B B
R R | B B B
```

Затем только:

```math
\frac{2}{3}
```

---

# 8. Стандарт проверки понимания

После примера ученик должен ответить хотя бы на один вопрос без вычислений:

- Почему этот метод подходит?
- Что было бы иначе при другом знаке?
- Какой шаг самый опасный?
- Как проверить ответ?
- Покажи идею рисунком/таблицей.
- Объясни младшему ученику одним предложением.

Если ученик может только повторить вычисления, понимание ещё хрупкое.

---

# 9. Mastery Gates

## Foundation gate

Тема освоена, если ученик:

- решает 4 из 5 базовых задач без подсказки;
- может объяснить правило словами;
- решает одну новую вариацию;
- не зависит от таймера.

## SAT Bridge gate

Тема освоена, если ученик:

- распознаёт pattern;
- выбирает эффективный method;
- держит accuracy ≥ 80–90%;
- решает transfer question;
- понимает ключевые SAT English phrases;
- после accuracy подключает time pressure.

---

# 10. Когда НЕ использовать timed practice

Не включать таймер, если ученик ещё:

- путает сам паттерн;
- не знает prerequisite;
- делает много вычислительных ошибок;
- читает English wording настолько медленно, что это мешает понять математику.

Сначала accuracy и understanding, потом speed.

---

# 11. Когда Desmos полезен

Для Foundation Desmos используется **после ручного понимания** как визуальная проверка.

Для SAT Bridge Desmos становится ещё и инструментом выбора стратегии.

Пример:

```text
Foundation:
решил y=2x+3 вручную → построил → увидел slope/intercept

SAT Bridge:
увидел messy intersection → сразу оценил, что graph быстрее
```

---

# 12. Lesson labels

Каждый урок или дополнительный блок может иметь метку:

- `FOUNDATION` — базовая идея;
- `BRIDGE` — соединяет школьную тему с SAT;
- `SAT CORE` — основная экзаменационная работа;
- `STRETCH` — hard / 750–800.

Это **не** то же самое, что Easy/Medium/Hard.

Difficulty говорит о сложности задачи.
Learner label говорит о готовности ученика.

---

# 13. Parent / teacher prompt

Для Foundation после каждого центрального примера полезно задать один вопрос:

> «Объясни мне, почему ты сделал именно этот первый шаг».

Если ребёнок отвечает только «потому что так правило», попросите показать идею на числах, рисунке или бытовом примере.

---

# 14. Definition of Done

Возрастно-адаптивный gateway lesson должен иметь:

- [ ] Prerequisite Gate;
- [ ] Foundation Bridge или ссылку на него;
- [ ] concrete/visual model;
- [ ] минимум один Think-Aloud Example;
- [ ] variation;
- [ ] faded example;
- [ ] vocabulary staging;
- [ ] check-for-understanding question;
- [ ] явное указание, когда переходить к SAT Drill 01;
- [ ] отдельный mastery gate без таймера для Foundation.
