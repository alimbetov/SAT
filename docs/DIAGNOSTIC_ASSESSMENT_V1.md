# Diagnostic Assessment V1 — SAT Math + English placement

**Статус:** D0 — проектирование выполнено; D1 — авторский банк 225 вопросов подготовлен и проходит структурный CI, независимая академическая ревизия ещё открыта; D2 — формы и протокол готовы, но реальные пилоты детей не проводились; D3–D5 — запланированы, не реализованы.

## 1. Цель

До назначения программы выявлять **конкретные пробелы знаний**, отличать отсутствие базового навыка от медленного решения и строить индивидуальный маршрут. Диагностика не является официальным SAT, не выдаёт официальных SAT scores и не сертифицирует CEFR.

Исходная база: ветка `feat/age-adaptive-pedagogy`, 25 уроков SAT Math, 624 существующих задания, Foundation и SAT Bridge. Новые диагностические вопросы дополняют, а не заменяют существующие `practice/` и `study_paths/`.

## 2. Три независимые шкалы

1. **Mastery/accuracy**: правильность и устойчивость знания по узкой теме, включая перенос на новый контекст.
2. **Readiness/understanding**: тип ошибки, объяснение выбранного действия, prerequisites, понимание английской формулировки задачи.
3. **Fluency/time**: скорость при условии, что навык уже освоен. Время в начальной диагностике **наблюдается, но не штрафует** результат.

По английскому разделяем **CEFR-aligned grammar screening A1–B2** и отдельную **SAT Reading and Writing readiness**. Уверенная грамматика B2 не означает автоматически высокий балл SAT; тест грамматики сам по себе не доказывает полноценный уровень CEFR.

## 3. Протокол по каждой теме

**Ровно 5 разных вопросов** в базовом наборе:

| № | Уровень проверки | Что диагностирует |
|---|---|---|
| 1 | Concept / recognition | Понимание определения или структуры |
| 2 | Basic application | Прямое применение |
| 3 | Independent application | Самостоятельный выбор метода |
| 4 | Trap / misconception | Типичная системная ошибка |
| 5 | Transfer / context | Применение в новой форме, задаче или контексте |

Для конкретной грамматической темы допустимы 5 MC-вопросов, но не 5 перефразированных копий одной конструкции. Вопросы желательно выравнивать по сложности внутри уровня. Все 4 варианта A/B/C/D должны быть грамматически и семантически проверены, правильный — единственным.

Для SAT Math после пилота добавлять также `student-produced response` (без вариантов): официальный экзамен содержит оба формата. Базовая диагностическая версия V1 использует MC для удобного ручного проведения, а не имитирует пропорцию реального экзамена.

**Ключ и объяснение строго отдельно от студенческого листа.** В версии преподавателя верный вариант подчёркнут `<u>...</u>`, за ним объяснение правила, ход решения и при необходимости пояснение ловушки. Ученик видит ключ только **после сохранения ответов**.

## 4. Объём и сессии

| Направление | Тем | По 5 | Сессии для SAT Bridge |
|---|---:|---:|---|
| SAT Math | 25 | 125 | 5 × 25 вопросов (5 тем) |
| English grammar A1 | 5 | 25 | 1 × 25 |
| English grammar A2 | 5 | 25 | 1 × 25 |
| English grammar B1 | 5 | 25 | 1 × 25 |
| English grammar B2 | 5 | 25 | 1 × 25 |
| **Итого обязательный банк** | **45** | **225** | **9 сессий** |

Дополнительно: 1–2 сессии English reading/vocabulary/SAT conventions, а для проверки writing/speaking/listening нужны самостоятельные задания и/или оценка преподавателя. Указанные 9 сессий — **полный базовый охват, не одно длинное тестирование**.

- Для SAT Bridge ориентир **4–5 тем по 5 вопросов / 30–45 минут**; разбивать по утомляемости.
- Для Foundation ориентир **2–3 темы по 5 вопросов / 20–30 минут**, без жёсткого лимита; сначала короткие prerequisite gates.
- В первый день: короткий входной скрининг и согласование маршрута, не все 225 вопросов. Остальные сессии — по необходимости и с адаптивным пропуском явно недоступных тем (статус **not assessed**, не «ноль знаний»).
- После первого прохода 2–3 новые задачи на пограничную тему, не повторяя виденные вопросы. Повторный контроль освоения: **5 новых задач** через 7–14 дней после изучения.

## 5. Порядок диагностики

1. Intake: класс/маршрут Foundation или SAT Bridge, цель, предполагаемая дата экзамена, родительские ограничения, предпочитаемый язык инструкции.
2. Foundation prerequisite mini-screen: арифметика, дроби, проценты, уравнения, чтение диаграмм. При провале нельзя интерпретировать продвинутые SAT темы как «низкий интеллект».
3. Math: 4 SAT content domains → 25 узких тем; соблюдать зависимости (`MATH_BLUEPRINT.md`).
4. English grammar: тестировать **последовательно A1 → A2 → B1 → B2**, при низкой уверенности останавливать и отмечать верхние уровни как not assessed; точный переход подтверждать новой выборкой.
5. English beyond grammar: vocabulary-in-context, reading comprehension/inference, punctuation/sentence boundaries, transitions/rhetorical synthesis. Для полной CEFR-оценки отдельно нужны listening/speaking/writing.
6. Разбор ошибок: не показывать объяснения до завершения темы; после фиксации ответов раскрыть ключ и предложить короткий вопрос «почему?».
7. Выпустить GAP REPORT → 2-недельный учебный план → mastery check → скорректировать маршрут.

## 6. Различать точность и причины ошибок

Использовать существующую таксономию Math: `R` pattern recognition, `M` method, `A` arithmetic/algebra, `L` language, `C` domain/constraints, `G` graph/data, `T` trap, `K` check. Добавлять `PR` prerequisite gap, `TM` timing constraint отдельно; основная причина и дополнительные причины хранятся раздельно.

English: `GRAM` grammar rule, `VOC` vocabulary, `READ` comprehension, `CONTEXT` context, `PUNC` punctuation, `RUSH` careless/rushed. Не присваивать причину автоматически только по неправильному варианту без анализа distractor.

## 7. Как формировать стратегию

Приоритет закрытия пробела = prerequisite dependency × impact on SAT × size of gap × evidence confidence. Не лечить «плохую геометрию» абстрактно: указывать точную тему и зависимость. Для Foundation сначала concrete → visual → verbal → symbolic. Для SAT Bridge: recognition → method selection → transfer → timed practice.

Результат: список `mastered_provisional / verify / gap / not_assessed`, карта prerequisite блокеров, конкретные ссылки на имеющиеся уроки, задачи проверки, дата контрольного теста, тренд по сессиям.

## 8. Успешность V1 / Definition of Done

- [ ] Есть список **25 Math + 20 English grammar** тем с идентификаторами, dependencies, ровно 5 диагностических позиций на тему.
- [ ] Пилотные вопросы проходят экспертную проверку однозначности; каждый содержит ключ и пояснение.
- [ ] В студенческом варианте **нет видимых правильных вариантов**.
- [ ] На каждую тему записываются timestamp start/end, paused duration, active duration, answers, correctness, error codes, question revision.
- [ ] Непройденные темы не смешиваются с ошибочными ответами.
- [ ] Отчёт отделяет грамматическую диагностику от CEFR и отдельно от SAT readiness.
- [ ] Повторная проверка использует **новые** задачи, а не выученные ответы.
- [ ] Для несовершеннолетних данные по умолчанию псевдонимизируются и не публикуются в Git.
- [ ] После реального пилота на детях и педагогической ревизии можно проектировать автоматизацию; никаких заявлений о валидированных уровнях/официальном SAT score до калибровки.

## 9. План реализации

| Slice | Результат | Критерий завершения |
|---|---|---|
| D0 — Design / pilot | Спецификация, blueprint, шкала, примеры | Материалы в отдельной ветке, экспертная ревизия |
| D1 — Question-bank authoring | 125 Math + 100 grammar уникальных вопросов/ключей | Ровно 5 на каждую тему, независимая проверка |
| D2 — Manual diagnostic acceptance | Сессии, бланк ответов, отчёт и учебный маршрут | Полный trace от ответа до рекомендации |
| D3 — Digital capture (опционально) | Учет времени/пауз, автопроверка, экспорт | Работает без утечки ключей |
| D4 — Calibration | Дополнительные формы, анализ неоднозначностей и сложности | Проверены надёжность и чувствительность диагностики |
| D5 — SAT simulation | Реальные модули, адаптация и grid-in, separate timing | Отдельная квалификация, не смешивать с D0 |
