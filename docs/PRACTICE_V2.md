# SAT Math Practice V2 — стандарт практики

## 1. Зачем нужен Practice V2

Теория курса уже построена по модели **Recognize → Pattern → Choose → Solve → Check → Transfer**. Практика должна продолжать ту же логику.

Старый формат `10 вопросов → ответы` хорошо проверяет количество решённых задач, но слабо учит переносу. Practice V2 превращает каждый набор в тренировочный цикл.

## 2. Семь функций задачи

Каждая targeted-задача получает одну основную педагогическую роль:

| Stage | Что тренируем | Что должен сделать ученик |
|---|---|---|
| **Recognition** | узнать семейство | назвать pattern до вычислений |
| **Core Pattern** | базовый метод | решить стандартным коротким способом |
| **Guided Variation** | изменение формы | заметить, что pattern не изменился |
| **Word Problem** | перевод текста | построить математическую модель |
| **Trap** | устойчивость к ошибке | объяснить, почему неверный путь неверен |
| **Transfer** | перенос | применить pattern в незнакомой форме |
| **Hard / 750–800** | выбор стратегии под давлением | выбрать самый эффективный метод |

## 3. Правило перед решением

Перед вычислениями ученик записывает три короткие строки:

```text
PATTERN: что это за тип задачи?
METHOD: какой метод выберу?
CHECK: как проверю ответ?
```

На ранних задачах cue может быть дан. На поздних cue исчезает.

## 4. Drill 01 — обучение и accuracy

Рекомендуемая структура 10 вопросов:

```text
Q1–Q2  Recognition
Q3–Q5  Core Pattern
Q6–Q7  Guided Variation
Q8     Word Problem
Q9     Trap
Q10    Transfer
```

Цель: ученик должен научиться **узнавать** задачу раньше, чем начинает считать.

Gate:

- 9–10/10 и верный pattern ≥ 9/10 → Drill 02;
- 7–8/10 → Error Clinic и повтор ошибочных pattern;
- ≤6/10 → возврат в lesson.

## 5. Drill 02 — hardening

Структура:

```text
Q1–Q2  Method Selection
Q3–Q5  Hard Variations
Q6–Q7  Trap Clinic
Q8–Q9  Transfer
Q10    750–800 Challenge
```

Здесь подсказок значительно меньше. Главная метрика — не только правильный ответ, но и правильный выбор метода.

## 6. Answer key V2

Ответ должен содержать четыре элемента:

```text
ANSWER
PATTERN
METHOD
COMMON ERROR
```

Пример:

```text
Answer: x = 6
Pattern: variable on both sides
Method: collect x-terms first
Common error: переносить член «со сменой знака» без эквивалентной операции
```

## 7. Mixed-domain sets

20-question domain sets уже не обучают один конкретный pattern. Они проверяют **pattern selection**.

Перед каждым вопросом подсказки не показываются. После выполнения answer key должен сообщить:

- skill;
- pattern;
- manual/Desmos choice;
- тип ошибки.

Рекомендуемая диагностическая таблица после set:

| Question | Correct? | Pattern recognized? | Method efficient? | Error code |
|---|---|---|---|---|

## 8. Timed modules

Timed modules остаются без scaffolding — иначе теряется экзаменационная валидность.

В самих 22-question modules **не добавляются** pattern cues.

Усиливается только post-test diagnostic key:

```text
question
→ domain
→ pattern
→ shortest valid method
→ trap
→ lesson/drill to review
```

## 9. Error taxonomy

Используем общие error codes:

| Code | Ошибка |
|---|---|
| `R` | Recognition — не распознан тип задачи |
| `M` | Method — выбран неэффективный/неверный метод |
| `A` | Algebra/Arithmetic — техническая ошибка |
| `L` | Language — неверно прочитан English cue |
| `C` | Constraint/Domain — потеряно ограничение |
| `G` | Graph/Data — неверно прочитан график/таблица |
| `T` | Trap — попался на типичную ловушку |
| `K` | Check — ответ не проверен или неверно интерпретирован |

## 10. Mastery

Тема считается действительно освоенной, когда ученик:

1. узнаёт pattern без подсказки;
2. выбирает короткий метод;
3. решает корректно;
4. объясняет ключевой шаг;
5. переносит метод на новую формулировку;
6. повторно не допускает ту же ошибку.

**Количество решённых задач — вторичная метрика. Основная метрика — устойчивое распознавание и перенос.**
