# SAT Math Pedagogy V2

Этот документ задаёт новый стандарт подачи материала в репозитории.

## Почему V1 недостаточно

Формат `формула → один пример → несколько задач` полезен как справочник, но слаб как самостоятельный курс. Ученик может понять уже решённый пример и всё равно не уметь решить новую задачу, потому что не научился распознавать **тип задачи** и выбирать **метод**.

Главная цель V2 — научить не запоминать решения, а видеть повторяющиеся структуры SAT.

---

# Главная учебная модель

Каждый навык изучается по циклу:

```text
RECOGNIZE
Что я вижу?
    ↓
PATTERN
На какой знакомый тип это похоже?
    ↓
CHOOSE
Какой метод здесь самый короткий и надёжный?
    ↓
SOLVE
Выполняю решение маленькими контролируемыми шагами
    ↓
CHECK
Ответ математически и по смыслу подходит?
    ↓
TRANSFER
Смогу ли я узнать тот же паттерн в другой формулировке?
```

Короткая версия для ученика:

> **Увидел → назвал паттерн → выбрал инструмент → решил → проверил.**

# Структура каждого урока V2

## 1. Карта темы — Pattern Map

В начале урока ученик должен видеть не список формул, а 4–8 наиболее частых типов задач.

Пример для Linear Equations:

| Что вижу | Паттерн | Что делаю |
|---|---|---|
| `3x+7=25` | isolate the variable | undo operations в обратном порядке |
| `5x+2=2x+17` | variable on both sides | собрать `x` на одной стороне |
| `3(x+4)=21` | parentheses | сначала искать короткий путь; иначе distributive property |
| `4x+5=4x+9` | variable disappears | определить no solution / infinitely many solutions |
| fixed fee + rate | linear word problem | `total = fixed + rate × quantity` |
| parameter `k` | make equations equivalent | сравнить coefficients/constants |

Цель: ученик до вычислений должен уметь сказать: **«Это задача такого-то типа»**.

---

## 2. Визуальный/смысловой якорь

Не просто формула, а короткий образ.

Примеры:

- equation = **весы**;
- slope = **rise/run**;
- vertex form = **адрес вершины**;
- percentage multiplier = **что осталось после изменения**;
- discriminant = **светофор числа roots**;
- conditional probability = **мы уже зашли внутрь одной группы**.

Якорь должен помогать восстановить правило без зубрёжки.

---

## 3. Pattern Card для каждого типа задачи

Каждый важный паттерн получает карточку:

### PATTERN: Variable on both sides

**Как узнать**

`x` встречается слева и справа.

**Цель**

Собрать все variable terms на одной стороне, constants — на другой.

**Алгоритм**

1. выбрать сторону, где удобнее оставить `x`;
2. убрать `x` с другой стороны;
3. убрать constant;
4. разделить на coefficient;
5. подставить ответ для проверки.

**Фраза ученика**

> «Сначала соберу все `x`, потом числа».

**Частая ошибка**

Менять знак без понимания операции.

**Когда Desmos не нужен**

Почти всегда: такая задача вручную быстрее.

---

## 4. Worked Example — преподаватель показывает всё

Первый пример решается полностью.

Но каждый шаг содержит четыре элемента:

1. **Notice** — что я заметил;
2. **Decision** — что решил сделать;
3. **Action** — вычисление;
4. **Check** — что контролирую.

Пример:

```text
Notice: x есть по обе стороны.
Decision: оставлю x слева, потому что 5x больше 2x.
Action: вычитаю 2x из обеих частей.
Check: знак и равенство сохранились.
```

Это не должно превращаться в длинную лекцию. Цель — показать принятие решения.

---

## 5. Worked Example Variation — тот же паттерн в другой одежде

Сразу после первого примера даётся почти такой же навык, но:

- другие числа;
- другой порядок членов;
- отрицательные коэффициенты;
- текстовая формулировка;
- другая искомая величина.

Ученик должен увидеть, что **внешний вид изменился, структура осталась**.

---

## 6. Faded Example — часть решения уже не дана

Scaffolding постепенно убирается.

### Уровень A

Все шаги показаны.

### Уровень B

Указан pattern, но действия выбирает ученик.

### Уровень C

Дан только вопрос: `Какой это паттерн?`

### Уровень D

Обычная SAT-style задача без подсказки.

Это предотвращает иллюзию понимания, когда ученик только читает готовые решения.

---

# Обязательная «лестница примеров»

Для каждого ключевого паттерна желательно иметь:

```text
Example 1 — прямой
Example 2 — тот же паттерн, другой вид
Example 3 — word problem
Example 4 — common trap
Example 5 — SAT Hard / parameter / hidden structure
```

Не каждый микропаттерн требует пяти примеров, но центральные темы требуют именно серии, а не одного решения.

# SAT Language Decoder

Отдельный блок учит переводить английские фразы в математику.

Пример:

| SAT phrase | Математический смысл |
|---|---|
| `is` | `=` |
| `is greater than` | `>` |
| `at least` | `≥` |
| `at most` | `≤` |
| `per` | rate / division |
| `increased by 20%` | `×1.20` |
| `decreased by 20%` | `×0.80` |
| `one-time fee` | fixed constant |
| `for each` | multiplication by quantity |
| `zeros / solutions / x-intercepts` | часто одна и та же идея в разных представлениях |

Это особенно важно для русскоязычного ученика.

# Method Selector — как выбирать метод

Урок не должен просто перечислять методы. Он должен объяснять, **когда какой выгоднее**.

Пример для quadratics:

```text
Вижу x² = number?
→ square root

Легко подобрать factors?
→ factoring

Вижу vertex form?
→ читаю vertex напрямую

Нужен только number of roots?
→ discriminant

Коэффициенты неудобные / графический вопрос?
→ Desmos

Нужна точная algebraic form?
→ quadratic formula / completing square
```

# Error Clinic вместо обычного списка ошибок

Каждая типичная ошибка оформляется как мини-задача.

### Ошибка

```math
3(x+4)=3x+4
```

### Почему мозг так делает

Ученик распределил `3` только на первый член.

### Как себя проверить

Перед раскрытием представить две стрелки:

```text
3 → x
3 → 4
```

### Мини-проверка

Раскройте:

```math
-2(3x-5)
```

Так ошибка сразу превращается в навык.

---

# Desmos должен преподаваться как стратегия

Не писать просто «можно использовать Desmos».

Для подходящих задач показывать:

1. что именно ввести;
2. что смотреть на графике;
3. как прочитать ответ;
4. когда ручной способ быстрее;
5. как проверить ручное решение.

Пример:

```text
y=x^2-6x+5
```

В Desmos:

- x-intercepts → roots;
- lowest point → vertex/minimum;
- y-intercept → значение при x=0.

Один график связывает несколько представлений.

# Transfer Questions — проверка настоящего понимания

После объяснения задавать вопросы без вычислений:

- «Что изменится, если coefficient станет отрицательным?»
- «Какой метод вы выберете и почему?»
- «Как понять число решений, не находя сами solutions?»
- «Какая часть выражения отвечает за fixed fee?»
- «Какой вариант ответа можно исключить ещё до вычислений?»

Если ученик может объяснить выбор метода, навык глубже, чем простое получение ответа.

# Новый стандарт practice

Обычный набор из 20 задач должен быть разделён по функции:

| Блок | Задач | Цель |
|---|---:|---|
| Recognition | 3–4 | назвать паттерн/метод без решения |
| Core skill | 5–6 | отработать алгоритм |
| Variation | 4–5 | тот же навык в другом представлении |
| Word problems | 2–3 | построить модель |
| Traps | 2 | научиться не ошибаться |
| Hard transfer | 2–3 | параметры / hidden structure / 750–800 |

Так 20 задач становятся обучающей последовательностью, а не случайным списком.

---

# Требование к языку

Пишем коротко и конкретно.

Плохо:

> Решим уравнение путём выполнения соответствующих эквивалентных преобразований.

Хорошо:

> Нам нужно оставить `x` один. `+7` мешает, поэтому отменяем его обратной операцией: вычитаем 7 с обеих сторон.

Английский SAT-термин всегда связываем с русским смыслом.

# Definition of Done для урока V2

Урок считается переработанным только если:

- [ ] есть Pattern Map;
- [ ] есть минимум 3 центральных pattern cards;
- [ ] есть визуальные/смысловые anchors;
- [ ] есть несколько worked examples, а не один;
- [ ] есть хотя бы один faded example;
- [ ] есть word-problem translation;
- [ ] есть SAT Language Decoder, если тема текстозависимая;
- [ ] есть Method Selector;
- [ ] Common Traps превращены в Error Clinic;
- [ ] Desmos объяснён пошагово, если применим;
- [ ] есть Transfer Questions;
- [ ] самостоятельная практика идёт после обучения, а не заменяет обучение.
