# Как использовать

Для каждой темы:

```text
Lesson
  ↓
Practice Problems внутри lesson
  ↓
Topic Drill 01 (10 questions)
  ↓
Error review
  ↓
Domain mixed set
  ↓
Timed module
```

Не переходите к следующему уровню только по количеству решённых задач. Рекомендуемый gate:

- **9–10/10** → тема готова к mixed practice;
- **7–8/10** → разобрать ошибки и повторить слабые типы;
- **≤6/10** → вернуться к lesson и Guided Example.
