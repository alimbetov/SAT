# Linear Equations — Practice V2 · Drill 01

**Goal:** научиться сначала узнавать паттерн, затем решать.

Перед каждым вопросом назовите `PATTERN`, затем `METHOD`, затем решайте.

## A. Recognition

1. **Easy · MC.** Which equation has the variable on both sides?  
A) `4x+3=19`  B) `7-2x=15`  C) `5x+8=2x+29`  D) `3(x-2)=21`

2. **Easy · MC.** After simplifying `4(x+2)=4x+9`, which outcome should you expect?  
A) one solution  B) no solution  C) infinitely many solutions  D) `x=1`

## B. Core Pattern

3. **Easy · SPR.** Solve `4x+3=19`.

4. **Easy · SPR.** Solve `7-2x=15`.

5. **Easy · SPR.** Solve `3(x-2)=21`.

## C. Guided Variation

> Cue for Q6: undo the outer operation first.

6. **Medium · SPR.** Solve `(x+3)/4=5`.

> Cue for Q7: simplify both sides before collecting x-terms.

7. **Medium · SPR.** Solve `2(3x-1)=4x+10`.

## D. Word Problem

8. **Medium · SPR.** A service charges `$22` initially plus `$6` per month. The total bill is `$88`. How many months were charged?

## E. Trap

9. **Hard · MC.** What is the solution set of `4(x+2)=4x+9`?  
A) `x=1/4`  B) `x=1`  C) no solution  D) infinitely many solutions

## F. Transfer

10. **750–800 · SPR.** The equation `(k+1)x-5=13` has solution `x=3`. What is `k`?

<details><summary><strong>Practice V2 answer key</strong></summary>

1. **C.** Pattern: variable on both sides. Method: collect x-terms. Common error: начинать вычисления, не распознав структуру.
2. **B.** Pattern: coefficients of `x` cancel but constants conflict. Method: simplify → `8=9`. Error code: `R/T`.
3. **4.** Pattern: `ax+b=c`. Method: undo `+3`, then `×4`. Check: `4(4)+3=19`.
4. **-4.** Pattern: two-step equation. Method: subtract 7, then divide by `-2`. Common error: sign mistake.
5. **9.** Pattern: parentheses with common outside factor. Method: divide by 3 first. Common error: unnecessary expansion.
6. **17.** Pattern: fraction as outer operation. Method: multiply by 4 → `x+3=20`.
7. **6.** Pattern: parentheses + variable both sides. Method: expand → collect → solve.
8. **11.** Pattern: `total=fixed+rate·quantity`. Model: `22+6m=88`.
9. **C.** Pattern: no solution. Method: simplify both sides; variable disappears and false statement remains.
10. **5.** Pattern: known solution + parameter. Method: substitute `x=3`: `3(k+1)-5=13`.
