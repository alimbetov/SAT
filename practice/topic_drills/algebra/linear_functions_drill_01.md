# Linear Functions — Practice V2 · Drill 01

**Anchor:** `slope = change per 1`, `intercept = starting value`.

## A. Recognition

1. **Easy · MC.** In `y=3x+7`, which number is the starting value?  
A) 3  B) 7  C) 10  D) x

2. **Easy · MC.** Which description is linear?  
A) doubles every hour  B) increases by 5 every hour  C) increases by 5% every hour  D) squares every input

## B. Core Pattern

3. **Easy · SPR.** What is the slope of `y=-4x+11`?

4. **Easy · SPR.** If `f(x)=4x-7`, find `f(6)`.

5. **Medium · SPR.** A table contains `(0,5),(2,11),(4,17)`. Find the slope.

## C. Guided Variation

6. **Medium · SPR.** Find the equation `y=mx+b` through `(2,5)` and `(6,13)`. Enter `b`.

7. **Medium · MC.** `A(t)=120+8t` models water in a tank. What does `8` mean?  
A) initial liters  B) liters added per minute  C) final liters  D) minutes

## D. Word Problem

8. **Medium · SPR.** Plan A costs `18+6x`; Plan B costs `9x`. At what `x` do they cost the same?

## E. Trap

9. **Hard · MC.** When using `m=(y2-y1)/(x2-x1)`, what must stay consistent?  
A) only numerator order  B) only denominator order  C) the same point order in numerator and denominator  D) signs do not matter

## F. Transfer

10. **Hard · SPR.** A linear function has `f(2)=7` and `f(5)=16`. Find `f(0)`.

<details><summary><strong>Practice V2 answer key</strong></summary>

1. **B.** Pattern: slope-intercept form; `b` is value at `x=0`.
2. **B.** Constant additive change → linear.
3. **-4.** Read `m` directly.
4. **17.** Function evaluation: substitute `x=6`.
5. **3.** Constant change: `+6` in y for `+2` in x.
6. **1.** Slope `2`; `5=2(2)+b`.
7. **B.** Slope in context = change in output per input unit.
8. **6.** `18+6x=9x`.
9. **C.** Error code `A/T`: mixed order flips only one sign and corrupts slope.
10. **1.** Slope `3`; `7=3(2)+b → b=1`.

</details>
