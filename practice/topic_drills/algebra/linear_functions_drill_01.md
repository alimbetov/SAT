# Linear Functions — Topic Drill 01

## Questions

1. **Easy · SPR.** If `f(x)=3x+2`, find `f(4)`.
2. **Easy · SPR.** A table contains `(0,5)`, `(2,11)`, `(4,17)`. What is the slope?
3. **Medium · SPR.** A linear function satisfies `f(1)=4` and `f(5)=12`. What is its slope?
4. **Medium · SPR.** A line has slope `-2` and passes through `(3,1)`. What is its `y`-intercept?
5. **Easy · MC.** In `V(t)=50-5t`, what does `50` represent?  
A) rate of decrease  B) initial value  C) time  D) final value
6. **Easy · SPR.** For `f(x)=4x-20`, what `x` makes `f(x)=0`?
7. **Medium · MC.** `f(x)=2x+3`. Function `g` contains `(0,1)` and `(2,9)`. Which has the greater rate of change?  
A) `f`  B) `g`  C) equal  D) cannot determine
8. **Medium · SPR.** Let `f(x)=2x+1` and `g(x)=x-3`. Find `f(g(5))`.
9. **Hard · SPR.** If `f(x)=kx+4` and `f(3)=19`, find `k`.
10. **750–800 · SPR.** A linear model gives value `18` at `t=2` and `33` at `t=7`. What value does the model predict at `t=10`?

<details><summary><strong>Answers</strong></summary>

1. **14**.
2. **3** — `(11-5)/(2-0)=3`.
3. **2** — `(12-4)/(5-1)=2`.
4. **7** — `1=-2(3)+b`.
5. **B** — value at `t=0`.
6. **5**.
7. **B** — `g` has slope `(9-1)/2=4`, greater than 2.
8. **5** — `g(5)=2`, then `f(2)=5`.
9. **5** — `3k+4=19`.
10. **42** — slope is `3`; from `t=7` to `10`, add `9`.

</details>
