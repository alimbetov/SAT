# Linear Functions — Topic Drill 02

## Questions

1. **Medium · MC.** A linear function contains points `(-1,1)`, `(0,4)`, `(1,7)`. Which rule matches?  
A) `f(x)=x+4`  B) `f(x)=3x+4`  C) `f(x)=4x+3`  D) `f(x)=3x+1`
2. **Medium · SPR.** If `f(x)=-2x+9`, solve `f(x)=1`.
3. **Medium · SPR.** A linear function satisfies `f(2)=11` and `f(8)=-1`. Find its slope.
4. **Medium · SPR.** Solve `g(x)=0` for `g(x)=5x-10`.
5. **Medium · SPR.** A car value is modeled by `V(t)=24000-1800t`. Find `V(6)`.
6. **Medium · MC.** `f(x)=3x+1`. Function `g` passes through `(0,5)` and `(2,9)`. Which has greater slope?  
A) `f`  B) `g`  C) equal  D) cannot determine
7. **Hard · SPR.** `h(x)=(k-2)x+7` is parallel to `y=4x-1`. Find `k`.
8. **Medium · SPR.** What is the slope of a line perpendicular to `y=(1/3)x+2`?
9. **Medium · SPR.** An arithmetic sequence follows `a_n=7+4(n-1)`. Find `a_10`.
10. **750–800 · SPR.** A line has `y`-intercept 6 and slope `-2`. Its `x`-intercept is `a`. Find `a`.

<details><summary><strong>Answers</strong></summary>

1. **B**.
2. **4**.
3. **-2**.
4. **2**.
5. **13200**.
6. **A** — slopes are 3 and 2.
7. **6**.
8. **-3**.
9. **43**.
10. **3** — `0=-2a+6`.
