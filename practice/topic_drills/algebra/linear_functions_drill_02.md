# Linear Functions — Practice V2 · Drill 02

## A. Method Selection

1. **Medium · MC.** A table has equal x-steps and equal y-differences. Which family should you test first?  
A) linear  B) exponential  C) quadratic  D) radical

2. **Medium · MC.** Values `5,10,20,40` occur for x=`0,1,2,3`. Which pattern is present?  
A) constant difference  B) constant ratio  C) no pattern  D) constant slope 5

## B. Hard Variations

3. **Medium · SPR.** A line passes through `(3,14)` and `(9,32)`. Find its slope.

4. **Medium · SPR.** If `f(x)=2.5x+4`, for what `x` is `f(x)=24`?

5. **Hard · SPR.** A linear function has `f(-2)=9` and `f(4)=-3`. Find `f(0)`.

## C. Trap Clinic

6. **Hard · SPR.** `y` increases by 18 when `x` increases by 6. What is the slope?

7. **Hard · MC.** Which equation is **not** linear?  
A) `y=3x-1`  B) `2x+y=8`  C) `y=4(1.2)^x`  D) `y=7`

## D. Transfer

8. **Hard · SPR.** Find the x-coordinate where `5x+2=2x+20` as an intersection of two linear functions.

9. **Hard · SPR.** A taxi costs `$7` at 0 miles and `$31` at 8 miles. Find the cost per mile.

## E. 750–800 Challenge

10. **750–800 · SPR.** A linear function satisfies `f(2)=11` and `f(8)=35`. Find the value of `x` for which `f(x)=51`.

<details><summary><strong>Practice V2 answer key</strong></summary>

1. **A.** Constant first difference → linear candidate.
2. **B.** Constant ratio 2 → exponential, not linear.
3. **3.** `18/6=3`.
4. **8.** `2.5x=20`.
5. **5.** Slope `-12/6=-2`; `9=-2(-2)+b → b=5`.
6. **3.** Rate is `18/6`, not 18. Error code `R` if units are ignored.
7. **C.** Variable is in exponent.
8. **6.** Intersection means equal outputs: `5x+2=2x+20`.
9. **3.** `(31-7)/(8-0)=24/8` dollars per mile.
10. **12.** Slope `4`, so `f(x)=4x+3`; solve `4x+3=51`.

</details>
