# Two-Variable Data and Scatterplots — Topic Drill 01

## Questions

1. **Easy · MC.** As `x` increases, `y` tends to increase. The association is  
A) positive  B) negative  C) none  D) causal
2. **Easy · MC.** As outside temperature increases, heating cost tends to decrease. The association is most likely  
A) positive  B) negative  C) none  D) quadratic by definition
3. **Easy · SPR.** A line of best fit is `y=3x+2`. Predict `y` when `x=4`.
4. **Medium · SPR.** A model predicts 14, but the observed value is 12. Find the residual `observed-predicted`.
5. **Medium · MC.** In `y=4.5x+20`, what does `4.5` represent?  
A) initial value  B) predicted change in `y` per 1-unit increase in `x`  C) residual  D) correlation coefficient
6. **Medium · MC.** A table has `x=0,1,2` and `y=2,4,8`. Which model type best matches the pattern?  
A) linear  B) exponential  C) constant  D) inverse
7. **Medium · MC.** A strong correlation between two variables proves that one causes the other.  
A) always true  B) usually true  C) false  D) true only for negative correlations
8. **Medium · MC.** A model is built using `x` values from 10 to 30. Predicting at `x=22` is  
A) interpolation  B) extrapolation  C) causation  D) randomization
9. **Medium · SPR.** A line passes through `(0,1)` and `(3,7)`. What is its slope?
10. **Hard · MC.** Model A predicts 50 when observed is 47. Model B predicts 43 when observed is 47. Which prediction has smaller absolute residual?  
A) A  B) B  C) equal  D) impossible to tell

<details><summary><strong>Answers</strong></summary>

1. **A**.
2. **B**.
3. **14**.
4. **-2**.
5. **B**.
6. **B** — values double.
7. **C**.
8. **A**.
9. **2**.
10. **A** — residual magnitudes are 3 and 4.

</details>
