# Digital SAT Math — Timed Module 02 (Hard Route)

**22 questions · 35 minutes**

Этот модуль моделирует более сложный второй Math module после сильного первого модуля. Задачи оригинальные и ориентированы на уровни `Medium → Hard → 750–800`.

---

## 1 · SPR
For what value of `a` does

```math
(a-2)x+5=4x+5
```

have infinitely many solutions?

```math

```

has slope `-1/3`. What is the slope of a line perpendicular to it?

A) `-3`  
B) `-1/3`  
C) `1/3`  
D) `3`
