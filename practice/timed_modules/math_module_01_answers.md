## Brief Solutions

### 1
```math
7x-5=30\Rightarrow7x=35\Rightarrow x=5
```

### 2
```math
m=\frac{12-4}{5-1}=\frac84=2
```

### 3
Slope-intercept form is `y=mx+b`, so `m=-3`, `b=8`.

### 4
Add the equations:
```math
2x=14\Rightarrow x=7
```

### 5
```math
-2x+4\le10
```
```math
-2x\le6
```
Divide by `-2` and reverse the inequality:
```math
x\ge-3
```

### 6
Find two numbers whose product is `12` and sum is `7`: `3` and `4`.

### 7
```math
x^2-8x+15=(x-3)(x-5)
```
Larger root: `5`.

### 8
In `y=(x-h)^2+k`, the vertex is `(h,k)`. Here `h=-2`, `k=-9`.

### 9
```math
27=3^3
```
so `x=3`.

### 10
A 12% decrease leaves `88% = 0.88` each year.

### 11
```math
\sqrt{x+1}=5\Rightarrow x+1=25\Rightarrow x=24
```

### 12
```math
x^2-16=(x-4)(x+4)
```
so `x≠4,-4`.

### 13
```math
150(0.80)=120
```

### 14
The high value `20` pulls the **mean** upward much more than the median.

### 15
```text
54% ± 3% → 51% to 57%
```

### 16
```math
9^2+12^2=81+144=225=15^2
```

### 17
In a `30-60-90` triangle, hypotenuse = `2 × shortest side = 12`.

### 18
```math
A=\pi r^2=25\pi
```

### 19
Circle form is `(x-h)^2+(y-k)^2=r^2`. Here `r^2=49`, so `r=7`.

### 20
Fixed fee = y-intercept `6`; rate per mile = slope `2.5`:
```math
C=2.5m+6
```

### 21
Exactly one real solution means discriminant `D=0`:
```math
(-10)^2-4(1)(k)=0
```
```math
100-4k=0\Rightarrow k=25
```

### 22
Random assignment helps balance confounding/lurking variables between treatment groups and supports causal inference.
