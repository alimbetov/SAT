## Brief Solutions

### 1
For infinitely many solutions, coefficients and constants must match:

```math
a-2=4\Rightarrow a=6.
```

### 2
A perpendicular slope is the negative reciprocal of `-1/3`, so it is `3`.

### 3
Substitute `y=x+2`:

```math
3x+2(x+2)=16
```

```math
5x=12\Rightarrow x=\frac{12}{5}.
```

### 4

```math
65+30h\le245
```

```math
30h\le180\Rightarrow h\le6.
```

### 5
Slope:

```math
m=\frac{16-7}{5-2}=3.
```

Moving from `x=5` to `x=8` adds 3 units of `x`, so output increases by `3×3=9`:

```math
f(8)=16+9=25.
```

### 6
One real solution means `D=0`:

```math
(k-2)^2-36=0
```

```math
k-2=\pm6
```

```math
k=8\text{ or }k=-4.
```

### 7
Complete the square:

```math
x^2-8x+13=(x-4)^2-3.
```

Vertex: `(4,-3)`.

### 8
For `x^2-9x+14`, the sum of roots is `9`. Therefore `2+r=9`, so `r=7`.

### 9
Factor theorem: `P(2)=0`.

```math
8+4k-8-8=0
```

```math
4k=8\Rightarrow k=2.
```

### 10

```math
400(1+r)^2=484
```

```math
(1+r)^2=1.21
```

```math
1+r=1.10\Rightarrow r=0.10=10\%.
```

### 11

```math
3\cdot2^{x+2}=3\cdot2^x\cdot2^2=12\cdot2^x.
```

### 12

```math
x+1=2(x-2)=2x-4
```

```math
x=5.
```

### 13
Square both sides:

```math
2x+3=x^2
```

```math
x^2-2x-3=0
```

Candidates are `3` and `-1`. The original equation requires the right side `x` to be nonnegative, so only `x=3` works.

### 14

```math
|x-4|<3
```

means

```math
-3<x-4<3
```

so

```math
1<x<7.
```

### 15
Use total points, not average of the two averages:

```math
\frac{20(70)+30(80)}{50}=\frac{3800}{50}=76.
```

### 16

```math
P(RR)=\frac4{10}\cdot\frac3{9}=\frac{12}{90}=\frac2{15}.
```

### 17
A much larger random sample generally has lower sampling variability and a smaller margin of error.

### 18

```math
residual=observed-predicted=30-27=3.
```

### 19
Scale factor:

```math
\frac{15}{10}=1.5.
```

Corresponding side:

```math
8(1.5)=12.
```

### 20
For `(5,3)`, displacement from center `(2,-1)` is `(3,4)`:

```math
\sqrt{3^2+4^2}=5,
```

equal to the radius.

### 21
When `θ` is in radians:

```math
s=r\theta=6\left(\frac\pi3\right)=2\pi.
```

### 22
`tan θ=3/4` corresponds to a `3-4-5` right triangle, so

```math
\sin\theta=\frac35.
```
