# Mathematics — diagnostic blueprint (25 topics × 5 = 125)

**Статус D1:** все 125 задач по 25 темам написаны: [пилот ALG-01](PILOT_MATH_LINEAR_EQUATIONS.md) и 4 дополнительных раздела [банка Math](bank/). Число 125 — фактический объём авторских заданий; независимая экспертная оценка и калибровка сложности пока не завершены. Существующие уроки и упражнения используются для remedial plan, но не копируются без проверки.

## Предварительный Foundation check (до сложных тем)

Для учащихся с неустойчивой базой сначала проверять: `FND-01` arithmetic & fractions; `FND-02` ratio/rate/percent; `FND-03` equation balance; `FND-04` coordinates; `FND-05` spatial reasoning, area/angles. Эти дополнительные prerequisite checks **не входят** в 125 SAT Math вопросов; формат: короткие 3–5 задач, без давления временем. При большом пробеле расширять нужный блок.

## Основной перечень

Для каждой строки подготовить **Q1 concept, Q2 direct, Q3 independent, Q4 misconception, Q5 transfer**, четыре варианта A/B/C/D, один ключ, объяснение и хотя бы один distractor с типовой ошибкой. Topic_ID фиксируется в ответах.

## Рекомендуемые пять диагностических сессий (SAT Bridge)

| Session | Темы | Количество |
|---|---|---:|
| M1 | ALG-01 … ALG-05 | 25 |
| M2 | ADV-01 … ADV-05 | 25 |
| M3 | ADV-06 … ADV-09 + PSD-01 | 25 |
| M4 | PSD-02 … PSD-06 | 25 |
| M5 | PSD-07 + GEO-01 … GEO-04 | 25 |

Порядок адаптивен: если ALG-01 системно провален, сначала восстановить prerequisite и отложить зависящие темы; **не записывать им 0/5 без проведения**. Для Foundation дробить каждый session на 2–3 короткие сессии.

## Validation checklist для автора каждого набора

- [ ] Ровно 5 пунктов, от concept до transfer (все не одинаковые).
- [ ] Проверен единственный корректный вариант; числовые и символьные ответы самостоятельно пересчитаны.
- [ ] Язык не является скрытым главным препятствием для Foundation; при необходимости существует RU перефразирование.
- [ ] Задача Q4 измеряет типичную ошибку, а не неоднозначную формулировку.
- [ ] У каждого вопроса есть `question_id`, `topic_id`, `revision`, `difficulty`, `error_code`, объяснение, `answer_key`.
- [ ] Верный ответ не подсвечен в студенческой секции; в отдельном ключе подчёркнут.
- [ ] Будущие контрольные задания отличаются числами, структурой или контекстом, не только перестановкой вариантов.
