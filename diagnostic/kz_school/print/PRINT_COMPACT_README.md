## Как распечатать
1. Откройте нужный `.html` на GitHub и нажмите **Download raw file / Скачать исходный файл** (не печатайте страницу GitHub с кодом).
2. Откройте скачанный файл локально в Chrome, Edge или другом браузере.
3. Нажмите **Ctrl+P** (macOS: **Cmd+P**). Установите: **A4**, ориентация **книжная**, масштаб **100%**, отключите верхние/нижние колонтитулы браузера.
4. Можно выбрать **Сохранить как PDF**, затем распечатать PDF. Не устанавливайте «2 страницы на лист» — макет уже двухколоночный.
5. Печать ключей только для взрослого; их нельзя выдавать ученикам.

Верстка рассчитана на экономную двухколоночную печать A4, но итоговое число страниц зависит от браузера, шрифтов и настройки принтера. Перед тиражированием проверьте предпросмотр и отсутствие разрыва вариантов ответа.
