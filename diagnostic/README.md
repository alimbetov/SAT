# Диагностика SAT: начало работы

Задача директории — **сначала определить пробелы, затем обучать**. Это спецификация и демонстрационные тесты, не веб-приложение.

## Маршрут

1. Прочитайте [требования](../docs/DIAGNOSTIC_ASSESSMENT_V1.md).
2. Выберите уровень готовности: Foundation или SAT Bridge (см. [текущие пути](../study_paths/)).
3. Математика: [25 тем и порядок](MATH_BLUEPRINT.md).
4. Английская грамматика: [20 тем A1–B2](ENGLISH_BLUEPRINT.md).
5. Тестовый пример по [линейным уравнениям](PILOT_MATH_LINEAR_EQUATIONS.md).
6. Тестовые примеры грамматики [A1–B2](PILOT_ENGLISH_A1_B2.md).
7. [Учёт времени, интерпретация и отчёт](SCORING_AND_TIMING.md).

## Правило для ребёнка

**Вопросы выдаются без ключей.** Не раскрывайте раздел `Answer key` до окончания темы. После ответа разберите не только правильную букву, но и причину ошибки; попросите ученика объяснить решение одним предложением.

## Рекомендуемый объём

- Вопросов на тему: **5**.
- SAT Bridge: до **5 тем / 25 вопросов** на сессию, обычно 30–45 минут.
- Foundation: **2–3 темы / 10–15 вопросов** на сессию, без давления временем.
- Математика: 25 тем, 125 вопросов для полного охвата.
- Английская грамматика: 20 тем, 100 вопросов для полного охвата.
- Дополнительно оценивать reading/vocabulary/SAT R&W; это отдельная шкала.

Готовность темы зависит от точности, переноса в новый контекст и prerequisites. Быстрое, но ошибочное выполнение — не mastery.

## Что реализовано сейчас

- Есть проектные требования и blueprints для создания полного банка.
- Есть **пилоты** по 1 математической и 4 английским грамматическим темам (5 вопросов на каждую).
- Остальные 40 тем диагностического банка запланированы, **не выдаются за готовые**.
- Нет автоматической записи времени, личных данных детей и автоматического расчёта статуса. До D3 измерения и анализ выполняются вручную по шаблону.
