# Grade 9 SAT Bridge Track

Этот маршрут рассчитан на ученика, который уже проходил базовую школьную алгебру и геометрию, но ещё не должен сразу работать как 750–800 scorer.

Главная цель:

```text
school math
→ SAT patterns
→ method selection
→ English wording
→ transfer
→ timed performance
```

---

# Step 0 — Prerequisite diagnostic

До timed practice проверьте пять базовых блоков.

## A. Arithmetic / fractions

Уверенно:

- operations with fractions;
- negative numbers;
- powers and square roots;
- decimal ↔ fraction ↔ percent.

## B. Algebra

Уверенно:

- `ax+b=c`;
- variable on both sides;
- distributive property;
- simple inequalities;
- substitution.

## C. Coordinates

Уверенно:

- points `(x,y)`;
- slope as change;
- graph of `y=mx+b`.

## D. Geometry

Уверенно:

- angle sums;
- perimeter/area;
- Pythagorean theorem;
- similarity basics.

## E. English math vocabulary

Понимать без перевода каждого слова:

- at least / at most;
- per;
- increased / decreased;
- solution / zero / intercept;
- slope / rate;
- mean / median;
- probability.

Если один блок заметно слаб, сначала использовать Foundation bridge именно по нему.

## Главный навык

Не «знать все формулы», а отвечать:

> Какой метод здесь короче и почему?

Например:

```text
x²=49
→ square root

x²-7x+12=0
→ factoring

exactly one real root
→ discriminant

messy graph intersection
→ Desmos may be efficient
```

# Stage 3 — PSDA

Порядок:

1. ratios/rates/units;
2. percentages;
3. one-variable statistics;
4. scatterplots/models;
5. probability;
6. sampling/margin of error;
7. studies/experiments.

Для каждой word problem ученик перед вычислениями пишет одну строку:

```text
What is the base / denominator / model / population?
```

Это снижает количество ошибок чтения.

# Stage 5 — Mixed transfer

После доменов:

- domain mixed sets;
- diagnostic maps;
- targeted repair.

Правило:

> Mixed set нужен не для изучения нового правила, а для проверки, узнаёт ли ученик правило без подсказки.

Если ошибка `R` — recognition problem → вернуться к Pattern Map.

Если `M` — method problem → сравнить два способа решения.

Если `A` — arithmetic/algebra → короткий accuracy drill.

---

# Stage 6 — Timed modules

Таймер подключается **после accuracy**.

Рекомендуемая последовательность:

```text
untimed mixed set
→ 90 sec/question soft target
→ full 35-minute module
```

Не следует одновременно учить новый материал и тренировать скорость.

---

# How to study one hard problem

После ошибки не читать решение пассивно.

Использовать protocol:

```text
1. Какой pattern я не увидел?
2. Где был первый неверный шаг?
3. Почему правильный method работает?
4. Решить заново без подсказки.
5. Решить похожую variation.
6. На следующий день сделать retrieval check.
```

# Parent / tutor prompts

Полезные вопросы для 9-классника:

- «Какой метод ты выбрал и почему?»
- «Можно ли решить быстрее другим способом?»
- «Что в условии было ключевой подсказкой?»
- «Как проверишь без повторения всего решения?»
- «В какой момент Desmos экономит время, а в какой мешает?»

# Mastery target

SAT Bridge readiness означает:

- strong conceptual accuracy;
- stable pattern recognition;
- reasonable English math fluency;
- ability to explain method choice;
- gradual speed increase without collapse in accuracy.

Только после этого имеет смысл системно переходить к 750–800 challenge sets.
