# Observational Studies and Experiments — наблюдательные исследования и эксперименты

## 1. Заголовок и краткое описание

**Evaluating statistical claims: observational studies and experiments** — официальный SAT skill. Нужно различать correlation и causation, понимать random assignment, random sampling, control groups и границы допустимых выводов.

> **Главная идея:** random sampling отвечает за «на кого можно обобщать», random assignment — за «можно ли говорить о причинности».

---

## 2. Ключевые понятия и формулы

| Понятие | Смысл |
|---|---|
| observational study | исследователь наблюдает, но не назначает treatment |
| experiment | исследователь назначает treatment |
| random sampling | помогает representative generalization |
| random assignment | помогает сравнить treatment groups и сделать causal inference |
| control group | baseline для сравнения |
| confounding variable | фактор, смешивающий влияние переменных |
| correlation | связь переменных, не обязательно causation |

### Ключевая логика SAT

- **Random sample, no random assignment** → можно лучше обобщать association, но причинность не доказана.
- **Random assignment** → при хорошем дизайне experiment можно поддержать causal claim.

### Визуальный якорь

**Sample → population. Assignment → causation.**

## 3. Пошаговый разбор — Guided Example

Researchers randomly assign 200 volunteers to two groups. One group receives a new study method; the other uses the standard method. The new-method group has higher average scores.

What conclusion is best supported?

### Шаг 1. Определяем тип исследования

Исследователи **назначили** treatment. Это experiment.

### Шаг 2. Ищем random assignment

Он есть. Это помогает сделать группы сопоставимыми.

### Шаг 3. Causal inference

Различие результатов может поддерживать утверждение, что new method **caused** an improvement для участников эксперимента.

### Шаг 4. Проверяем generalization

Участники — volunteers, а не random sample всей population. Поэтому нельзя автоматически утверждать, что эффект будет таким же у всех школьников страны.

## 4. Practice Problems — задачи для закрепления

### Problem 1 — Easy — Multiple Choice

Researchers record students' sleep hours and grades without changing behavior. This is:

**A)** experiment  
**B)** observational study  
**C)** random assignment  
**D)** controlled treatment

### Problem 2 — Easy — Multiple Choice

Which feature most directly supports a causal conclusion?

**A)** large graph  
**B)** random assignment to treatments  
**C)** high correlation only  
**D)** voluntary survey

### Problem 3 — Medium — Multiple Choice

A random sample of city residents is surveyed about exercise and health. More exercise is associated with better health. Which conclusion is justified?

**A)** exercise definitely causes better health  
**B)** there is an association in the population  
**C)** all residents who exercise are healthy  
**D)** the survey is an experiment

### Problem 4 — Medium — Multiple Choice

What is the main purpose of a control group?

**A)** guarantee a larger sample  
**B)** create a comparison baseline  
**C)** remove every source of error  
**D)** make all variables equal

### Problem 5 — Hard — Multiple Choice

A randomized experiment uses volunteers recruited from one sports club. Which statement is strongest?

**A)** causal inference may be possible for participants, but broad generalization is limited  
**B)** results automatically apply to all adults  
**C)** no causal inference is ever possible  
**D)** random assignment guarantees representative sampling

<details><summary><strong>Ответы и краткие решения</strong></summary>

1. **B**.  
2. **B**.  
3. **B**: association can be generalized more reasonably because of random sampling, but causation is not established.  
4. **B**.  
5. **A**: random assignment helps causal inference; volunteer recruitment limits generalization.

</details>

## 5. Common Traps — типичные ловушки

- Делать causal claim из correlation.
- Путать random sampling и random assignment.
- Считать большой sample автоматически representative.
