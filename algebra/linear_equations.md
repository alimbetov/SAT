# Linear Equations — линейные уравнения с одной переменной

## 1. Зачем эта тема нужна на SAT

Линейные уравнения — один из базовых навыков раздела **Algebra**, который составляет примерно 35% SAT Math. На экзамене важно не только решить уравнение, но и распознать его в текстовой задаче, понять смысл коэффициентов и определить, имеет ли уравнение одно решение, ни одного или бесконечно много решений.

> **Главная идея:** уравнение — это весы. Всё, что вы делаете с одной стороной, нужно сделать и с другой.

**Вопрос перед началом:** если к обеим чашам весов добавить одинаковый груз, останутся ли весы в равновесии? Именно на этом принципе построено решение уравнений.

---

## 2. Ключевые понятия и формулы

### Что такое линейное уравнение?

Линейное уравнение с одной переменной можно привести к виду:

```math
ax+b=c
```

где:

- `x` — неизвестная переменная;
- `a`, `b`, `c` — числа;
- `a \ne 0` для обычного случая с единственным решением.

Пример:

```math
3x+7=25
```

### Главные понятия

| Термин | Что означает | Пример |
|---|---|---|
| **variable** | неизвестная величина | `x` |
| **coefficient** | число перед переменной | в `5x` коэффициент равен `5` |
| **constant** | число без переменной | `+7`, `-3` |
| **solution** | значение переменной, которое делает равенство верным | для `x+2=5` решение `x=3` |
| **equivalent equations** | уравнения с одинаковым множеством решений | `2x=10` и `x=5` |

### Основной принцип равенства

Если:

```math
a=b
```

то можно выполнить одинаковое допустимое действие с обеими сторонами:

```math
a+c=b+c
```

```math
a-c=b-c
```

```math
ac=bc
```

и, если `c \ne 0`:

```math
\frac{a}{c}=\frac{b}{c}
```

### Визуальный якорь: «уравнение = весы»

```text
ЛЕВАЯ ЧАСТЬ  ⚖  ПРАВАЯ ЧАСТЬ
   3x + 7         25
```

Если убрать `7` только слева, равновесие нарушится. Поэтому вычитаем `7` **с обеих сторон**.

### Базовый алгоритм

Для уравнения вида:

```math
ax+b=c
```

обычно удобно:

1. убрать константу `b`;
2. разделить на коэффициент `a`;
3. проверить ответ подстановкой.

Например:

```math
3x+7=25
```

```math
3x=18
```

```math
x=6
```

Проверка:

```math
3(6)+7=25
```

```math
25=25
```

### Переменная с обеих сторон

Пример:

```math
5x+2=2x+17
```

Собираем все `x` на одной стороне:

```math
3x+2=17
```

затем числа — на другой:

```math
3x=15
```

```math
x=5
```

### Скобки и distributive property

```math
a(b+c)=ab+ac
```

Например:

```math
3(x+4)=21
```

можно решить двумя способами.

**Способ 1 — сначала разделить на 3:**

```math
x+4=7
```

```math
x=3
```

**Способ 2 — раскрыть скобки:**

```math
3x+12=21
```

```math
3x=9
```

```math
x=3
```

> На SAT выбирайте путь с меньшим количеством действий. Чем меньше шагов, тем меньше вероятность арифметической ошибки.

### Три возможных результата

| Результат | Что получается | Вывод |
|---|---|---|
| `x = число` | например `x=4` | одно решение (*one solution*) |
| ложное равенство | например `0=7` | нет решений (*no solution*) |
| верное равенство | например `0=0` | бесконечно много решений (*infinitely many solutions*) |

#### Нет решений

```math
3(x+2)=3x+10
```

```math
3x+6=3x+10
```

```math
6=10
```

Это невозможно, значит **no solution**.

#### Бесконечно много решений

```math
4(x-2)=4x-8
```

```math
4x-8=4x-8
```

Получилось тождество, верное при любом `x`, значит **infinitely many solutions**.

### Быстрая проверка понимания

Как вы думаете, что произойдёт с уравнением

```math
2(x+5)=2x+10
```

после раскрытия скобок? Попробуйте ответить до перехода к примеру.

## 3. Пошаговый разбор — Guided Example

### Задача

A streaming service charges a one-time activation fee of `$18` and `$7` per month. A customer paid `$81` in total. How many months did the customer use the service?

Пусть `m` — количество месяцев.

### Шаг 1. Переводим текст в математическую модель

Есть две части стоимости:

- фиксированная плата: `$18`;
- ежемесячная плата: `$7m`.

Поэтому:

```math
18+7m=81
```

**Почему именно так?**

Потому что общая стоимость складывается из фиксированной части и переменной части, зависящей от числа месяцев.

### Шаг 2. Изолируем член с переменной

Вычитаем `18` из обеих частей:

```math
18+7m-18=81-18
```

```math
7m=63
```

**Почему вычитаем 18?**

Наша цель — оставить выражение с `m` отдельно. `18` прибавляется к `7m`, поэтому используем обратную операцию — вычитание.

### Шаг 3. Находим `m`

Делим обе части на `7`:

```math
m=9
```

**Почему делим на 7?**

`7m` означает `7 \times m`. Чтобы оставить только `m`, применяем обратную операцию — деление на `7`.

### Шаг 4. Проверяем смысл ответа

```math
18+7(9)=18+63=81
```

Ответ соответствует условию.

**Ответ: `9 months`.**

### Что SAT проверяет в этой задаче на самом деле?

Не сложную алгебру. Экзамен проверяет, сможете ли вы:

1. выделить фиксированную величину;
2. определить величину «за единицу»;
3. построить линейное уравнение;
4. интерпретировать найденное значение в контексте.

## 5. Common Traps — типичные ловушки

### Ловушка 1. Менять знак «по памяти»

Ученики часто говорят: «переносим `+7` вправо, поэтому будет `-7`».

Это может дать правильный результат, но скрывает логику.

Лучше мыслить так:

```math
3x+7=25
```

**Вычитаем 7 из обеих частей:**

```math
3x+7-7=25-7
```

Так меньше вероятность ошибиться в более сложных уравнениях.

### Ловушка 2. Раскрыть скобки только частично

Неверно:

```math
3(x+4)=3x+4
```

Правильно:

```math
3(x+4)=3x+12
```

Число перед скобками умножается **на каждый член внутри скобок**.

Визуальный якорь:

```text
        ┌──→ x
3  ─────┤
        └──→ 4
```

### Ловушка 3. Не различать `no solution` и `infinitely many solutions`

Запомните:

```text
0 = 5  → невозможно → NO SOLUTION
0 = 0  → всегда верно → INFINITELY MANY SOLUTIONS
```

Если переменная полностью исчезла, не пытайтесь продолжать «искать x». Сначала оцените оставшееся равенство.

## 6. Стратегия для Digital SAT

### Когда решать вручную

Большинство простых линейных уравнений быстрее решить без калькулятора.

Например:

```math
7x+4=39
```

```math
7x=35
```

```math
x=5
```

### Когда Desmos полезен

Desmos особенно полезен, если:

- уравнение содержит неудобные дроби или десятичные числа;
- нужно быстро проверить ответ;
- задача сравнивает две линейные модели;
- уравнение удобно представить как пересечение двух графиков.

Например:

```math
2.7x+4.6=18.1
```

можно ввести:

```text
y = 2.7x + 4.6
y = 18.1
```

`x`-координата точки пересечения будет решением.

### Но не превращайте Desmos в костыль

Если уравнение решается за 10–20 секунд вручную, ввод графиков может занять больше времени.

> **Практическое правило:** простая алгебра → вручную; неудобные числа или сложная проверка → Desmos.

### Адаптивный формат

Первый Math module содержит смесь уровней сложности. Результат первого модуля влияет на сложность второго. Поэтому на базовых заданиях важно:

- не терять баллы из-за знаковых ошибок;
- не тратить две минуты на задачу, которая должна решаться быстро;
- сохранять время для более сложных вопросов ближе к концу модуля.

## 7. Связи с другими темами

### На что опирается эта тема

Перед линейными уравнениями желательно уверенно владеть:

- арифметикой целых чисел;
- отрицательными числами;
- дробями и десятичными числами;
- порядком действий;
- distributive property.

### Что идёт дальше

```text
Linear Equations
      ↓
Linear Functions
      ↓
Systems of Equations
      ↓
Linear Inequalities
      ↓
Word Problems / Modeling
```

Линейные уравнения также постоянно используются в Advanced Math, даже когда основная тема задачи — quadratic, exponential или rational expression.

### Вопрос для переноса навыка

Если вы умеете решить

```math
3x+5=20
```

сможете ли вы решить

```math
3f(x)+5=20
```

относительно `f(x)`?

Да. Алгебраическая идея та же: рассматривайте `f(x)` как неизвестную величину.
