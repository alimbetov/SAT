# Linear Inequalities — линейные неравенства

## 1. Зачем эта тема нужна на SAT

Линейные неравенства входят в официальный домен **Algebra**. На SAT они появляются как обычные выражения, диапазоны допустимых значений, бюджетные ограничения, минимальные/максимальные требования и области на координатной плоскости.

> **Главная идея:** уравнение обычно ищет точное значение, а неравенство описывает диапазон возможных значений.

**Вопрос перед началом:** чем математически отличаются фразы «ровно 18 лет» и «не менее 18 лет»?

---

## 2. Ключевые понятия и формулы

### Основные знаки

| Знак | Читается | Пример |
|---|---|---|
| `<` | меньше | `x<5` |
| `>` | больше | `x>5` |
| `\le` | меньше или равно | `x\le5` |
| `\ge` | больше или равно | `x\ge5` |

### Решение как диапазон

Например:

```math
x>3
```

означает все числа больше 3: `4`, `10`, `3.5`, `1000` и т. д.

### Главное правило

С неравенствами можно выполнять почти те же операции, что и с уравнениями.

Но есть критическое исключение:

> При умножении или делении обеих частей на **отрицательное число** знак неравенства переворачивается.

Пример:

```math
-2x>8
```

Делим на `-2`:

```math
x<-4
```

### Визуальный якорь: «минус разворачивает стрелку»

```text
÷ positive → знак остаётся
÷ negative → знак разворачивается
```

### Почему знак меняется?

Известно:

```math
2<5
```

Умножим оба числа на `-1`:

```math
-2>-5
```

На числовой прямой порядок отрицательных чисел оказался обратным.

### Open и closed endpoint

Для:

```math
x>3
```

число `3` **не входит** в множество решений.

Для:

```math
x\ge3
```

число `3` **входит**.

Визуально:

```text
x > 3   → open circle
x ≥ 3   → closed circle
```

### Compound inequalities

Пример:

```math
2<x\le7
```

означает одновременно:

```math
x>2
```

и

```math
x\le7
```

То есть `x` находится между 2 и 7, при этом 2 не входит, а 7 входит.

### Неравенства в двух переменных

Например:

```math
y>2x+1
```

решением является не одна линия, а целая область **выше** линии `y=2x+1`.

Если знак строгий (`<` или `>`), граница не входит. Если `\le` или `\ge`, граница входит.

## 3. Пошаговый разбор — Guided Example

### Задача

A student has `$120` to spend on a calculator and notebooks. The calculator costs `$48`, and each notebook costs `$9`. What is the greatest number of notebooks the student can buy without spending more than `$120`?

Пусть `n` — количество notebooks.

### Шаг 1. Переводим ограничение в знак

Фраза **without spending more than $120** означает:

```math
\text{cost}\le120
```

Это ключевой смысловой шаг.

### Шаг 2. Строим выражение стоимости

Калькулятор стоит `$48`, notebooks — `$9n`:

```math
48+9n\le120
```

### Шаг 3. Убираем фиксированную стоимость

```math
9n\le72
```

**Почему знак не меняется?**

Мы вычли `48`, а не умножали/делили на отрицательное число.

### Шаг 4. Делим на 9

```math
n\le8
```

### Шаг 5. Интерпретируем ответ

Вопрос просит **greatest number** notebooks. Максимальное целое значение, удовлетворяющее условию:

```math
n=8
```

**Ответ: `8`.**

## 5. Common Traps — типичные ловушки

### Ловушка 1. Не перевернуть знак при делении на отрицательное число

Неверно:

```math
-3x>12 \Rightarrow x> -4
```

Правильно:

```math
-3x>12 \Rightarrow x<-4
```

### Ловушка 2. Путать `at least` и `at most`

Запомните:

```text
at least  → не меньше → ≥
at most   → не больше → ≤
more than → >
less than → <
```

### Ловушка 3. Игнорировать реальный смысл ответа

Если получилось:

```math
n\le6.8
```

и `n` — количество билетов, нельзя купить `6.8` билета. Максимальное целое значение — `6`.

Контекст может менять финальную интерпретацию алгебраического результата.

## 6. Стратегия для Digital SAT

### Desmos для одной переменной

Простое неравенство обычно быстрее решить вручную.

Но Desmos полезен для проверки, особенно при сложных коэффициентах.

### Desmos для двух переменных

Введите:

```text
y > 2x + 1
```

Desmos заштрихует область решений.

Это особенно удобно в вопросах типа:

> Which point lies in the solution region?

Можно визуально проверить положение точки.

### Быстрый тест точки

Если варианты ответа — координаты, часто быстрее **подставлять точки** в неравенство, чем строить всю область.

Например, для

```math
y>3x-2
```

подставьте `(x,y)` каждого варианта и ищите верное утверждение.

### SAT-слова-маркеры

При чтении word problem сразу отмечайте:

```text
at least
at most
minimum
maximum
no more than
no less than
```

Они часто определяют знак неравенства ещё до вычислений.
