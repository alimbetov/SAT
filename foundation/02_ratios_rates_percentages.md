# Foundation Bridge 02 — Ratios, Rates, and Percentages

**Learner label:** `FOUNDATION`

# 1. Ratio — сравниваем две группы

Есть 2 красных и 3 синих шарика:

```text
R R | B B B
```

Ratio red : blue =

```text
2 : 3
```

Это читается:

> two red for every three blue.

## Очень важный порядок

`red : blue = 2:3`

Но:

`blue : red = 3:2`

Числа те же, смысл другой.

### Check

Если 4 кошки и 6 собак:

- cats : dogs = `4:6 = 2:3`;
- dogs : cats = `6:4 = 3:2`.

---

# 2. Ratio to total

Если 2 red и 3 blue, всего:

```math
2+3=5
```

Тогда:

```text
red : total = 2 : 5
```

Это уже не `2:3`.

## Worked Example 1

В классе 12 девочек и 8 мальчиков.

### Girls : boys

```text
12 : 8 = 3 : 2
```

### Girls : total

Всего:

```math
12+8=20
```

```text
12 : 20 = 3 : 5
```

Главная мысль:

> Перед fraction/ratio подпишите словами, что находится сверху и снизу.

# 3. Unit rate — сколько на 1

3 тетради стоят 900 тенге.

Сколько стоит одна?

Можно разложить:

```text
900 тг
↓ делим на 3 одинаковые тетради
300 тг за 1 тетрадь
```

```math
900÷3=300
```

Это **unit rate**.

### SAT word

`per` = «на каждый / за один».

```text
300 tenge per notebook
```

---

# 4. Worked Example — два возможных rates

Автомобиль проехал 120 km за 2 hours.

### km per hour

```math
120÷2=60
```

```text
60 km/hour
```

Но если спросить hours per km:

```math
2÷120=1/60
```

Это другой rate.

Главный вопрос:

> Что должно оказаться «на 1»?

# 5. Table model

Цена одного билета 700 тг.

| tickets | cost |
|---:|---:|
| 1 | 700 |
| 2 | 1400 |
| 3 | 2100 |
| 5 | 3500 |

Каждый раз:

```math
cost=700·tickets
```

Это proportional relationship.

Почему?

Потому что цена **за один билет** не меняется.

# 6. Percent means «из 100»

`percent` буквально означает «per hundred» — на сто.

```text
50% = 50 out of 100
25% = 25 out of 100
10% = 10 out of 100
1%  = 1 out of 100
```

## Visual bar

```text
100%  ██████████
50%   █████
25%   ██▌
10%   █
```

---

# 7. Полезные mental anchors

## 50%

Половина.

```math
50\%\ of\ 80=40
```

## 25%

Четверть.

```math
25\%\ of\ 80=20
```

## 10%

Разделить на 10.

```math
10\%\ of\ 80=8
```

## 5%

Половина от 10%.

```math
5\%\ of\ 80=4
```

## 1%

Разделить на 100.

```math
1\%\ of\ 300=3
```

Эти якоря дают смысл до decimal multiplier.

---

# 8. Worked Example — 30% of 80

## Method A — через 10%

10% of 80:

```math
80÷10=8
```

30% — это три раза по 10%:

```math
8·3=24
```

## Method B — decimal

```math
30\%=0.30
```

```math
80·0.30=24
```

Оба метода показывают одну идею.

Для Foundation сначала полезнее Method A.

# 9. Base — что здесь равно 100%?

Ключевой вопрос процентов:

> **100% = что?**

Если цена была 2000 тг и выросла на 10%, исходные 2000 тг — это 100%.

10% от 2000:

```math
200
```

Новая цена:

```math
2000+200=2200
```

Позже это можно записать короче:

```math
2000·1.10=2200
```

Но сначала надо понимать, откуда взялось `1.10`.

---

# 10. Почему +20%, потом -20% не возвращает назад

Начнём со 100.

Increase 20%:

```math
100→120
```

Теперь decrease 20% берётся уже **от 120**:

20% of 120:

```math
24
```

```math
120-24=96
```

Получили 96.

Главная мысль:

> percentages могут быть одинаковыми, но bases разными.

# 11. Faded Example


# 12. SAT English Bridge

| English | Meaning |
|---|---|
| per | на один / за каждый |
| for every | на каждые |
| percent of | процент от |
| increased by | увеличено на |
| decreased by | уменьшено на |
| original price | исходная цена |
| discount | скидка |

Example:

> What is 25% of 80?

```text
25% → one quarter
of → от
80 → base
```

Answer = 20.
