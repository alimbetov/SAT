# Foundation Bridge 01 — Equation Balance

**Learner label:** `FOUNDATION`

Цель — понять уравнение до формального SAT Algebra.

Главная мысль:

> Equation — это утверждение, что две стороны имеют одинаковое значение.

---

# 1. Начинаем без x

Посмотрите:

```text
□ + 7 = 12
```

Что должно быть в коробке?

Можно подумать так:

```text
? + 7 = 12
```

Чтобы узнать `?`, отменяем `+7`:

```text
12 - 7 = 5
```

Значит:

```text
□ = 5
```

## Почему это работает?

Потому что вопрос звучит так:

> «Какое число вместе с 7 даёт 12?»

---

# 2. Весы

Представьте:

```text
[ □ + 7 ]   ⚖   [ 12 ]
```

Если убрать 7 только слева:

```text
[ □ ]       ⚖   [ 12 ]
```

равновесие нарушится.

Поэтому убираем 7 **с обеих сторон**:

```text
[ □ + 7 - 7 ]   ⚖   [ 12 - 7 ]
```

Получаем:

```text
[ □ ]           ⚖   [ 5 ]
```

Это и есть смысл algebraic operation.

---

# 3. Переходим к x

Теперь просто меняем значок:

```text
□ + 7 = 12
```

на

```math
x+7=12
```

`x` — это та же неизвестная коробка.

### Worked Example 1

```math
x+9=15
```

**Что известно?**

К неизвестному числу прибавили 9 и получили 15.

**Что мешает увидеть x?**

`+9`.

**Как отменить +9?**

Вычесть 9.

```math
x+9-9=15-9
```

```math
x=6
```

**Check:**

```math
6+9=15
```

---

# 4. Если x умножили

```text
3□ = 18
```

Это означает:

```text
□ + □ + □ = 18
```

Если три одинаковые группы вместе дают 18, одна группа:

```math
18÷3=6
```

Значит:

```math
3x=18
```

```math
x=6
```

### Worked Example 2

```math
5x=35
```

`5x` означает 5 одинаковых групп по `x`.

Чтобы найти одну группу:

```math
x=35÷5=7
```

**Check:**

```math
5·7=35
```

---

# 5. Два шага

Теперь:

```math
3x+7=25
```

## Think Aloud

### Notice

С `x` сделали два действия:

```text
x
↓ ×3
3x
↓ +7
3x+7
```

### Decision

Чтобы вернуться к `x`, идём назад.

Сначала отменяем `+7`.

```math
3x+7-7=25-7
```

```math
3x=18
```

Теперь отменяем `×3`:

```math
x=6
```

### Check

```math
3·6+7=18+7=25
```

---

# 6. Почему «перенести через равно» — плохая первая модель

Иногда говорят:

> «+7 переносим вправо, знак меняется».

Это сокращение, но оно скрывает смысл.

Надёжнее думать:

```text
Я вычитаю 7 с обеих сторон.
```

Тогда в сложных задачах меньше ошибок.

---

# 7. Same Pattern, Different Clothes

### Example A

```math
4x+5=21
```

1. `-5` с обеих сторон:

```math
4x=16
```

2. `÷4`:

```math
x=4
```

### Example B

```math
2x-3=11
```

1. Чтобы отменить `-3`, прибавляем 3:

```math
2x=14
```

2. Делим на 2:

```math
x=7
```

# 8. Faded Example

Решите:

```math
6x+4=34
```

Заполните:

```text
Что мешает 6x? ______
Обратное действие: ______
После первого шага: ______
Что делаем дальше? ______
Ответ: ______
```

<details><summary>Проверка</summary>

```text
Что мешает 6x? +4
Обратное действие: -4
После первого шага: 6x=30
Что делаем дальше? делим на 6
Ответ: x=5
```

</details>

# 9. Word Problem Bridge

У Маши было несколько наклеек. Ей подарили 8, и стало 20.

Сколько было сначала?

## Step 1 — Unknown

Пусть было `x`.

## Step 2 — Story → equation

```math
x+8=20
```

## Step 3 — Undo

```math
x=12
```

## Step 4 — Check story

```text
12 было + 8 подарили = 20
```

---

# 10. SAT English Bridge

Позже вы увидите:

> A number increased by 8 is 20.

Перевод по смыслу:

```text
a number → x
increased by 8 → +8
is → =
20 → 20
```

Получаем:

```math
x+8=20
```

Сначала понимаем математику, потом английскую упаковку.
